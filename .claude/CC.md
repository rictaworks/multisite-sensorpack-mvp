# CC：コンプライアンスチェック 10項目（法律・権利・ルール遵守）

| 番号 | 項目 | 内容 |
| --- | --- | --- |
| CC01 | 商標権の侵害チェック | 使用しているロゴ・名称が他社の登録商標を侵害していないか（特許庁・J-PlatPat等で調査） |
| CC02 | 著作権の適正使用 | 画像・文章・音楽などが適切にライセンスされているか（フリー素材含め出典明記） |
| CC03 | 利用規約の整備 | サービス利用者向けの明確な利用規約が存在しているか |
| CC04 | プライバシーポリシーの記載 | 個人情報保護法に則った記述があるか（Cookie取得含む） |
| CC05 | 特定商取引法対応（ECサイトの場合） | ECサイトであれば「特商法に基づく表記」があるか |
| CC06 | 表示義務項目の記載 | 会社名、所在地、責任者名など、法令に基づく記載が必要な項目が漏れていないか |
| CC07 | 医療・美容など業種特有の表現規制 | 「効果がある」「治る」など、景品表示法・薬機法などに抵触していないか |
| CC08 | Cookie同意取得（改正電気通信事業法/GDPR対応） | 明確な同意取得とオプトアウト対応がされているか |
| CC09 | AI・生成物の明記 | AI生成コンテンツが含まれる場合、それを明示しているか（近年のトレンド） |
| CC10 | 法的リスクレビュー済み | 弁護士または法務担当者の監修・チェックが入っているか（可能な範囲で） |
