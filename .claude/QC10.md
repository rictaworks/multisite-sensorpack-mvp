# QC10：品質管理の10項目（チェックリスト）

| 番号 | 項目 | 内容 |
| --- | --- | --- |
| QC01 | W3Cバリデーション | HTML/CSSが構文的に正しいか（validator.w3.org） |
| QC02 | SEO基礎設定 | title / description / OGP の適切な設定 |
| QC03 | ページスピード | PageSpeed Insights でモバイル/PCスコア確認（60以上推奨） |
| QC04 | モバイル対応 | スマホ表示でのレイアウト崩れなし、レスポンシブ対応 |
| QC05 | 構造化データ | schema.orgやJSON-LDを正しく記述し、テストツールで検証済みか |
| QC06 | HTTPS対応 | 全ページがHTTPS化、混在コンテンツなし |
| QC07 | アクセシビリティ対応 | WCAG準拠、キーボード操作や音声読み上げに対応しているか |
| QC08 | Cookie & プライバシー法対応 | GDPR、日本の電気通信法等への対応、バナー表示など |
| QC09 | CMS・ライブラリの更新 | WordPress・JSライブラリなどが最新版で脆弱性なし |
| QC10 | エラーハンドリング | 404/500ページの整備、適切なリダイレクト・エラー表示あり |
