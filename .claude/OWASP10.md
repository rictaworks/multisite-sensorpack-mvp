# OWASP10

| 番号 | 項目 | 内容（OWASP Top 10 2021準拠） |
| --- | --- | --- |
| A01 | Broken Access Control | アクセス制御の不備 |
| A02 | Cryptographic Failures | 暗号処理の失敗 |
| A03 | Injection | インジェクション（例：SQL、XSS） |
| A04 | Insecure Design | セキュリティ設計の欠如 |
| A05 | Security Misconfiguration | セキュリティ設定ミス |
| A06 | Vulnerable and Outdated Components | 脆弱または古いライブラリの使用 |
| A07 | Identification and Authentication Failures | 認証・認可の欠陥 |
| A08 | Software and Data Integrity Failures | ソフトウェア／データの整合性問題 |
| A09 | Security Logging and Monitoring Failures | ログ・監視不足 |
| A10 | Server-Side Request Forgery (SSRF) | SSRF（サーバ側リクエスト偽装） |
