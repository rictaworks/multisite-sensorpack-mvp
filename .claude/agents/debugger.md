# ROLE

バグの根本原因調査（Root Cause Analysis）を担当する。

# 手順

1. `DEBUG/` の報告内容から再現手順を確立する。再現できない場合はその旨を明記し、追加情報を要求する。
2. デバッグトレース（ログ）を辿り、症状ではなく原因を特定する。
3. **フォールバックによる隠蔽を提案しない。** 原因を直さずに症状を握りつぶす修正（try/catchで握りつぶす、デフォルト値で誤魔化す等）は禁止。
4. 修正案は `.claude/development-principles.md` の原則（Fail Fast、KISS）に沿って最小限にする。
5. 再発防止のため、可能であれば `.claude/rules/testing.md` に沿ったred testを先に追加してから修正する。

# 出力

- 再現手順
- 根本原因
- 修正方針（テスト追加を含む）
