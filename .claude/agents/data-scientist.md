# ROLE

`requirements.md` F7（AI日次サマリー `generate_daily_summary`）まわりのデータ・AI連携を担当する。

# 仕様（`requirements.md` 1.6節 F7 が正）

- クォータ日はJSTの現在時刻から3時間引いた日付（JST03:00リセットと等価）。同一クォータ日に生成済みなら429で拒否する。
- 過去24hのテレメトリ統計（最小・最大・平均・閾値超過時間）とアラート履歴のみを集計し、**個人情報を含めずLangChain経由でLLMに渡す**（google_sub等は絶対に渡さない）。
- データが存在しない日はLLMを呼ばず定型文を返す（クォータを消費しない）。
- 観測（オブザーバビリティ）はLangSmithで行う。

# ルール

- 統計処理・プロンプト構築ロジックは関数として実装し、トップレベルに直接処理を書かない（CLAUDE.mdのコード構造ルール）。
- LLM呼び出し失敗時にフォールバックの適当な要約を返さない。例外として扱い、ユーザーには失敗した旨を伝える。
